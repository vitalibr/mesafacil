# MesaFácil

[English below](#english)

Gerador gratuito de mesas de solda e acessórios, com arquivos DXF prontos para corte a laser.

**Use o site:** <https://mesafacil.vmgarage.com.br/>

Este repositório só mantém o endereço antigo, vitalibr.github.io/mesafacil/, redirecionando para o
